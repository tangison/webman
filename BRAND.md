# Documentation and Visual Governance

This repository does not redefine Tangison Studio's corporate identity. It governs the presentation of the skill library.

## Voice

Direct, specific, calm, procedural, proof-led, and understandable by weaker GLM models. Use short sentences and explicit verbs. Avoid vague best-practice language, inflated claims, and philosophical filler.

## Composition

Use Markdown hierarchy, short sections, numbered procedures, compact tables, and exact paths. Do not decorate technical documentation with meaningless visual elements.

## Identity and assets

No logo asset is bundled because no official Webman identity asset was supplied in the recovered workspace. Another agent must not invent one. Any future official mark must be preserved exactly and recorded in ASSET_MANIFEST.md.

## Accessibility

Use descriptive headings, plain-language links, readable tables, and text alternatives for informative visuals. Do not encode meaning only through colour.

## Prohibited patterns

Generic startup claims, fabricated popularity, fake install counts, fake rankings, invented performance claims, arbitrary gradients, and AI-generated logos are prohibited.
