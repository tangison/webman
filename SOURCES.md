## Agent Skills format

- Source: [Agent Skills specification](https://agentskills.io/specification)
- Accessed: 2026-08-02
- Verified requirements: one skill directory containing SKILL.md; YAML frontmatter; required name and description; name matches directory; lowercase letters, numbers, and hyphens; maximum name length 64; maximum description length 1024.
