# Harness Capability Standard

Detect capabilities by purpose: repository, filesystem, shell, browser, skills, connectors, image, documents, testing, audit, deployment, model, and referenced-file loading.

Probe before claiming availability. Prefer installed Agent Skills, then direct repository reading, then a complete copy-paste prompt. Phrase product features conditionally when environments vary.

When a capability is unavailable, select the nearest safe supported workflow and record the check that remains unperformed. Never invent a tool result.
