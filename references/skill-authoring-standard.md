# Skill Authoring Standard

Use lowercase hyphenated names. Frontmatter must contain only name and description. The directory name and frontmatter name must match.

Every skill must define purpose, trigger, non-trigger, ownership, required inputs, inspection order, authority gates, tools and fallbacks, numbered procedure, verification, proof, failure handling, completion, and handoff.

Write short direct instructions for GLM-class models. Repeat critical safety and proof rules inside the standalone skill. Never rely on hidden context or an unverified installer.

Promote a skill only when no quality dimension scores below 3, the average is at least 4, and verification and proof both score 5.
