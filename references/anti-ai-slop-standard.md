# Anti-AI Slop Standard

Start visual work with a source-backed reference ledger. Abstract principles, never protected expression.

Reject generic gradients, random glow, floating glass, decorative blobs, meaningless grids, excessive pills, repeated rounded cards, arbitrary heading lines, fake metrics, fake testimonials, generic team stock, and interchangeable black-gold styling.

Define one organisation-specific idea, one focal point, and a clear hierarchy. Remove elements without purpose. If the design still fits an unrelated organisation after changing only the logo, revise it.
