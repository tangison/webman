# Product

## Statement

Tangison Universal Skills V2 is a public, proof-first, cross-harness skill library for Tangison Studio work across websites, identity, promotional design, imagery, formal and editorial documents, business planning, finance, funding, research, and project handoff.

## Audience

Tangison Studio and capable AI agents using GLM and ZCode, Claude Code, Codex, Cursor, Windsurf, Kimi Code, Gemini CLI, OpenCode, Agent Skills-compatible environments, generic shell harnesses, and chat-only environments.

## Objective

Make Tangison workflows portable without depending on one provider while preventing early completion, fabricated tool output, hidden scope reduction, duplicate ownership, generic design, and unsupported facts.

## Confirmed boundaries

- Webman is the canonical portable source.
- The package contains 25 canonical Tangison skills.
- Every skill supports installed, direct-reading, and copy-paste use.
- Proof and verification are mandatory.
- SkillsCamp is not modified or packaged as an application.
- External skill bodies are not copied into this library.

## Success criteria

Every canonical skill is substantive, uniquely named, GLM-readable, proof-driven, manifest-backed, scenario-routed, and free of placeholder shortcuts. Another agent can read SYSTEM.md and continue without chat history.
