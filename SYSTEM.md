# Tangison Universal Skills V2 System

## Operating mode

Production-quality portable skill library. Starter-only handoff in this archive. Webman is canonical. SkillsCamp is excluded by the user's later instruction and remains untouched.

## Reading order

1. SYSTEM.md
2. PRODUCT.md
3. BUILD_PLAN.md
4. MIGRATION_AUDIT.md
5. SKILL_INDEX.md
6. ROUTING_MATRIX.md
7. The selected owner SKILL.md
8. Relevant supporting skills and references
9. PROOF.md before any completion claim

## Exact deliverable

Maintain 25 canonical Tangison skills, 7 prompt packs, 10 shared standards, generated manifests, deterministic validators, routing scenarios, templates, and evidence records.

## Operating rules

- Select exactly one owner skill for each material decision.
- Inspect real harness capabilities before using tools.
- Preserve verified facts and authentic assets.
- Count approved outputs before writing.
- Do not invent tools, sources, tests, installations, deployments, or remote state.
- Do not use placeholders, TODO omissions, or prose instead of implementation.
- Do not deploy, delete, archive, force-push, or modify the legacy SkillsCamp website without separate authority.

## Autonomous execution loop

Select one bounded outcome. Name its owner and pass criterion. Execute it. Verify it after the latest change. Record evidence. Correct root causes. Continue until all approved outcomes pass or an authority decision blocks progress.

## Release gate

A completion claim without evidence is invalid. Run repository validation, routing scenarios, prompt-pack validation, duplicate detection, link validation, secret scanning, and archive inventory checks. Record all results in PROOF.md.
